# 風險登錄表與安全互鎖規格 (Risk Register & Safety Interlocks)

> 文件版本：v1.0.0  
> 階段：Phase 0 需求凍結與法規界線  
> 適用軟體：專業純音聽力測驗工具 (HearingTest)

---

## 1. 軟硬體安全互鎖架構 (Safety Interlocks)

為防止任何可能的聽覺不適或電聲意外，軟體實作五重防護屏障：

1. **數位強度硬上限 (Digital Ceiling Interlock)**：
   - 測驗強度白名單嚴格限制在 `0, 5, 10, 15, 20, 25, 30, 35, 40, 45, 50 dB HL`。
   - 禁止任何非 5 dB 之步進，禁止輸入大於 50 dB HL 之數值。
   - 到達 50 dB HL 受測者仍無反應時，強制標記為 `NR @ 50 dB HL`，不允許自動或手動繼續上調。
2. **無 Click 升降餘弦平滑 (Raised-Cosine Windowing)**：
   - 所有純音刺激與窄頻噪音開始與結束皆套用平滑漸入漸出（Ramp-in / Ramp-out，>20 ms），杜絕方波瞬間切換造成的暫態破音（Transient Click）。
3. **裝置異常立即靜音 (Fail-Safe Mute-On-Fault)**：
   - 音訊驅動若發生緩衝區下溢（Buffer Underrun）、USB 線材脫落、取樣率變更或 Windows 混音裝置變動，音訊引擎在 5 ms 內執行強制硬體靜音（Mute/Flush），並終止當前刺激序列。
4. **全域緊急停止鍵 (Global Emergency E-Stop)**：
   - UI 畫面常駐鮮紅色大尺寸「緊急停止」按鈕，同時綁定鍵盤 `Esc` 鍵。
   - 點擊後立即中斷音訊輸出緒、釋放裝置資源並記錄事件時間戳。
5. **未校正強制防呆 (Uncalibrated Guard)**：
   - 缺少有效校正檔或硬體指紋不符時，UI 全程鎖定顯示「研究相對刻度 (Relative dBFS)」，鎖死「dB HL」標籤與醫療報告產出功能。
