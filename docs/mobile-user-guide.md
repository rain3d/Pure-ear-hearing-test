## 1. 系統概述與特色

本手機版聽力測驗系統是專為智慧型手機與行動裝置打造的漸進式網頁應用（Progressive Web App, PWA）。無須自第三方下載未知 APK，透過手機瀏覽器即可直接將其轉換為**全螢幕、無網址列、支援觸覺震動的原生 App**。

### 🌟 六大核心優勢
- **極致純淨電聲（零爆音）**：利用微秒級硬體音訊時鐘，內建 **25ms 升降餘弦窗（Raised-Cosine Windowing）**，杜絕方波切換造成的暫態喀答破音（Click）。
- **立體聲雙耳獨立隔離**：純音發聲時嚴格分離左聲道與右聲道，防止串音洩漏。
- **標準 Hughson-Westlake（10-down / 5-up）尋閾演算法**：完全遵循醫院臨床聽力室標準階梯逼近與 2-of-3 確立準則。
- **嚴格防盲目瞎猜偵測**：2 秒實體發聲（3 秒反應時間視窗）、1 ~ 3 秒隨機靜音空白間隔，靜音期間按鍵觸發震動警告並扣除信度評分。
- **高解析動態聽力圖**：自動繪製國際標準聽力圖（右紅圈 `O`、左藍叉 `X`），即時計算 PTA 純音平均聽力級。
- **離線支援與防螢幕休眠**：內建 Service Worker 支援離線快取，測驗中自動呼叫 WakeLock API 保持手機螢幕常亮。

## 2. 快速連線與手機安裝指南

### 步驟 1：啟動本機伺服器
在電腦專案根目錄中，直接雙擊執行：
👉 **`啟動手機版測驗.bat`**  
*(終端機視窗會自動偵測並顯示您的本機局域網路 IP，例如 `http://192.168.x.x:8080`)*

---

### 步驟 2：手機連線與安裝為桌面 App

#### 🟢 安卓手機（Android）
1. 請確認手機已連線至與電腦相同的 **Wi-Fi 網路**。
2. 打開手機的 **Google Chrome** 或系統瀏覽器，在網址列輸入終端機顯示的網址（例如：`http://192.168.x.x:8080`）。
3. 點擊 Chrome 右上角 **「三個點（⋮）」** 選單。
4. 點選 **「安裝應用程式」**（或 **「加到主螢幕」**）。
5. 系統會自動為您在手機桌面生成獨立的 **「聽力測驗」App 圖示**。點開即全螢幕運行，完全沒有瀏覽器網址列！

#### 🍎 蘋果手機（iPhone / iOS）
1. 手機連線至同一 Wi-Fi，打開 **Safari 瀏覽器** 輸入相同網址。
2. 點擊 Safari 底部工具列中央的 **「分享按鈕（向上箭頭）」**。
3. 下滑選擇 **「加入主畫面」**，點擊右上角「新增」。
4. 手機桌面即會出現原生 App 圖示。

## 3. 測驗前準備與環境建議

為確保量測結果具備最高精確度與可靠性，請遵守以下黃金守則：

1. **耳機選擇**：
   - 推薦使用**密閉耳罩式耳機**或**貼合入耳式耳機**，隔音效果最佳。
   - 戴上耳機時，請確認**「L（左耳）」與「R（右耳）」佩戴方向正確**。
2. **手機音訊設定**：
   - **關閉手機音效等化器**：請至手機「設定 ➔ 聲音與震動」，將 Dolby Atmos（杜比全景聲）、音效等化器（EQ）或空間音訊**關閉**，確保純音平直輸出。
   - **固定手機音量**：測驗前將手機側邊的媒體音量滑桿設定在 **50%**，測驗全程**嚴禁旋轉或調整音量**。
3. **環境噪音控制**：
   - 請選擇深夜或門窗緊閉、無冷氣強風直吹的極安靜房間（背景環境噪音建議低於 40 dBA）。

## 4. 測驗流程與防盲猜規則

```
[點擊開始] ➔ [隨機1~2.5s緩衝] ➔ [實體發聲 2 秒 (3秒反應視窗)] ➔ [聽到立即點擊] ➔ [隨機 1~3s 空白停留] ➔ [自動播放下一音]
                                               │                                                 ▲
                                               └────────── 3秒未聽見 ➔ 自動升 5 dB ───────────────┘
```

1. **一鍵全自動開始**：
   - 戴上耳機，在首頁點擊藍色大按鈕 **「🎧 戴上耳機，開始測驗」**。
   - 系統進入測驗畫面，給予隨機緩衝準備後，**全自動播放第 1 個測試音**。
2. **3 秒反應視窗（2 秒實體發聲）**：
   - 每音實體發聲 **2 秒鐘**，但總反應視窗長達 **3 秒鐘**（發聲結束後仍有 1 秒靜音緩衝可確認反應）。
   - **只要隱約聽到聲音，立即點擊螢幕中央巨大的綠色【我聽到了！】按鈕**。
   - 聲音會在您按下的瞬間**立即停止發聲**（避免長時間大音量刺激耳膜），並微秒級記錄您的反應時間。
   - 判定聽見後，系統遵循標準降 10 dB；若 3 秒結束未按鍵，系統自動判定未聽見並升 5 dB。
3. **雙重防盲目瞎猜機制 (對照靜音 + 隨機空白停留)**：
   - **隨機 1.0 ~ 3.0 秒空白停留**：在每回測試音之間隨機靜音停留，徹底打破時間規律，防止受測者數拍子盲按。若在空白停留期間按鍵，手機立即觸發長震動警告並記錄假陽性。
   - **對照靜音試驗 (Catch Trial)**：測驗進行中，系統會隨機穿插「零音量對照試驗」（畫面進度條與雷達波正常運行，但耳機完全不發出測試音）。
     * 若受測者憑直覺瞎猜盲按，系統即刻捕捉假陽性（`False Positive +1`），手機震動警告並提示：
       > `⚠️ 盲猜警示！剛才為【對照靜音 (Catch Trial)】，系統未播放測試音，請確實聽見再按鍵！（已記錄假陽性）`
     * 對照靜音試驗**絕不影響目前聽閾搜尋階梯音量**（不會因此降 10 dB 或升 5 dB）。
     * 若受測者專注聆聽且未盲猜按鍵（正確拒斥 Correct Rejection），系統將順利過關並累積高信度評分。
4. **自動雙耳切換**：
   - 依序測試 **左耳（1000, 2000, 4000, 8000, 500, 250 Hz）** ➔ 自動切換至 **右耳（相同 6 個頻率）**。
   - 全程約 3 ~ 5 分鐘，結束後自動跳轉至聽力圖與信度統計報告。

## 5. 動態聽力圖判讀與聽損分級

測驗完成後，系統會自動在畫面上繪製專業聽力圖（Audiogram）：

### 📈 標記與座標說明
- **右耳（Right Ear）**：以**紅色圓圈（`O`）**標記，折線為紅色實線。
- **左耳（Left Ear）**：以**藍色叉叉（`X`）**標記，折線為藍色虛線。
- **垂直座標（分貝 dB HL）**：0 在最上方，50 在最下方（數值越小代表聽力越敏銳，向下掉代表需要越大聲才聽得到）。
- **水平座標（頻率 Hz）**：從左至右為 250 Hz（低沉低音）到 8000 Hz（尖銳高音）。

### 🟢 綠色正常聽力帶（0 ~ 25 dB HL）
- 聽力圖上方有一層淺綠色高亮區間（0 ~ 25 dB HL）。
- **若雙耳的折線全程落在綠色區間內**，代表各頻率聽力非常敏銳健康。

### 📊 世界衛生組織（WHO）四分法純音平均聽力級（PTA）
系統會自動計算 500 Hz、1000 Hz、2000 Hz、4000 Hz 四個核心言語頻率的平均分貝（PTA）：
| 純音平均值 (PTA) | 聽力等級分類 | 日常生活影響說明 |
| :--- | :--- | :--- |
| **0 ~ 20 dB HL** | **正常聽力 (Normal)** | 能輕鬆聽見微風拂葉、耳語聲。 |
| **21 ~ 35 dB HL** | **輕度聽損 (Mild)** | 在安靜環境聽正常講話沒問題，但在嘈雜環境下聽輕聲耳語略感吃力。 |
| **36 ~ 50 dB HL** | **中度聽損 (Moderate)** | 正常距離交談常需要對方重複或說大聲一點。 |
| **> 50 dB HL** | **顯著聽損 (Severe)** | 一般交談難以聽清，建議至醫院由耳鼻喉科醫師及聽力師進行臨床複查。 |

## 6. 手機分貝計快速校準教學

若您手邊有第二支手機，可使用「分貝計 App」對耳機輸出進行物理聲壓對齊：

1. **安裝 App**：在第二支手機上下載分貝計 App（iOS 推薦 **NIOSH Sound Level Meter**；Android 可使用專業 Sound Meter）。
2. **開啟校正頁面**：在測驗系統底部的導覽列點選 **「校正」**。
3. **實施量測**：
   - 選取測試單體（例如：左耳單體）。
   - 將耳機發聲面**緊密緊貼在第二支手機底部的收音孔上**（四周不可有縫隙漏氣）。
   - 點擊 **「🔊 播放 1000Hz 參考音」**。
   - 查看分貝計 App 顯示的讀數（例如：`68.5 dB SPL`），然後按「⏹️ 停止」。
4. **套用儲存**：
   - 在左耳實測欄位填入 `68.5`，點擊 **「⚡ 計算並儲存校正檔」**。
   - 系統即會依據國際 ISO 389-1 RETSPL 頻率曲線建立全頻補償，首頁徽章會亮起綠色 **【✓ 已校正 (手機基準)】**！

## 7. 常見問題與疑難排解 (FAQ)

### Q1：手機輸入網址後顯示「無法連線至此網站」？
1. **確認同一 Wi-Fi**：手機不能開行動網路（4G/5G），必須與電腦連接同一個無線基地台。
2. **檢查電腦伺服器狀態**：請確認電腦上的黑底命令提示字元視窗（`node mobile-web/server.js`）是否正在運行中。若已關閉，請重新雙擊 `啟動手機版測驗.bat`。
3. **防火牆阻擋**：Windows 防火牆若跳出詢問提示，請務必點選「允許在私人網路中存取」。

---

### Q2：測驗開始後耳機聽不到聲音？
1. 請確認手機未開啟硬體側邊的「靜音開關」，並確認媒體音量非 0。
2. 若使用藍牙耳機，請在手機藍牙設定中確認耳機連線正常，並先隨意播放一首 YouTube 音樂測試發聲。
3. 聽力測驗以 30 dB HL 起測，若耳機靈敏度極低或使用者高頻有所退化，初期幾秒可能感覺微弱，請專注耐心等待系統自動往上推進。

---

### Q3：測驗結果能匯出或截圖嗎？
測驗完成後，聽力圖會固定於「聽力圖」頁籤中。您可以直接使用手機的「電源鍵 + 音量減」進行全螢幕截圖保存，或隨時點擊「🔄 重新測驗」再次檢測！
