### 快速連線摘要 (Quick Start)
1. 雙擊工作區根目錄的 `啟動手機版測驗.bat`。
2. 手機連線同一個 Wi-Fi，打開手機瀏覽器輸入視窗顯示的連線網址（例如：`http://<您的電腦IP>:8080`）
3. 點選 Chrome 選單「安裝應用程式」或「加到主螢幕」即可像原生 App 一樣使用！
4. 介面頂部可隨時切換「繁體中文 / 简体中文 / English」。

### Quick Start Guide
1. Double-click `啟動手機版測驗.bat` in the project root directory.
2. Connect your mobile phone to the same local Wi-Fi network and navigate to the address shown in the console (e.g., `http://<YOUR_PC_IP>:8080`).
3. Tap the browser menu and select **"Install app"** or **"Add to Home Screen"** to experience full-screen PWA functionality.
4. Easily switch between **Traditional Chinese**, **Simplified Chinese**, and **English** using the language selector in the top navigation bar.
