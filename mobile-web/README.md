### 快速連線摘要 (Quick Start)
1. 雙擊工作區根目錄的 `啟動手機版測驗.bat`。
2. 手機連線同一個 Wi-Fi，打開手機瀏覽器輸入視窗顯示的連線網址（例如：`http://<您的電腦IP>:8080`）
3. 點選 Chrome 選單「安裝應用程式」或「加到主螢幕」即可像原生 App 一樣使用！
4. 介面頂部可隨時切換「繁體中文 / 简体中文 / English」。

### 重要安全警語與免責聲明 (Safety Warning & Disclaimer)
- ⚠️ **耳機音量務必先調低**：測試前請務必**先將耳機音量調至低音量**再開始測試，切勿以過高音量直接施測，以防突發大音量損害聽力！
- ⚖️ **非醫療器材免責聲明**：本工具僅供個人日常聽力趨勢追蹤與科學研究，非主管機關查驗核准之臨床醫療器材，亦無醫療診斷效力。若有急性聽力異常請盡速就醫。

### Quick Start Guide
1. Double-click `啟動手機版測驗.bat` in the project root directory.
2. Connect your mobile phone to the same local Wi-Fi network and navigate to the address shown in the console (e.g., `http://<YOUR_PC_IP>:8080`).
3. Tap the browser menu and select **"Install app"** or **"Add to Home Screen"** to experience full-screen PWA functionality.
4. Easily switch between **Traditional Chinese**, **Simplified Chinese**, and **English** using the language selector in the top navigation bar.

### Safety Warning & Disclaimer
- ⚠️ **Always Lower Headphone Volume First**: Always turn down your headphone or phone volume to a low level before testing. Never begin tests at high volume to prevent accidental acoustic trauma!
- ⚖️ **Non-Medical Disclaimer**: This utility is strictly for personal trend monitoring and scientific research; it is NOT a certified medical device and provides no official clinical diagnosis. Consult an ENT specialist if you notice sudden hearing changes.
